# ASTRA Post-Launch Roadmap

## High priority after launch

1. Replace GitHub-collaborator CMS access with ASTRA-managed roles (Editor, Publisher, Admin) and server-side repository mutation.
2. Expand CMS coverage to People, Platforms, and shared Media where operationally useful.

## Maintenance

- Review and enable Open Graph metadata where useful.
- Optimize large images without changing approved visual content.
- Maintain GitHub Actions, including Node 20 deprecation and Ubuntu runner migrations.
- Improve browser/Playwright QA coverage.

## Optional future development

- A richer dashboard and role-management interface.
- Broader DAM/media-library features.
- Structured links among Research, Projects, Publications, and Platforms.
- Appropriate analytics and privacy improvements.

The current launch does not require Research Axis CMS, a broad visual redesign, a broad CSS refactor, or rewriting the stable News/Project CMS.
